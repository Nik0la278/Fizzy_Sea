#Fizzy Sea 1.0 (Windows)
Download the .rar file.
Extract the .rar file that contains the game folder.
Run .exe file in the folder (If it doesn't run, try Running As Administrator)

Press WASD keys for movement.
Press Space for Jump.
Press C to Switch cameras (1st person and 3rd person).
Hold L Shift to sprint.
That's it! Enjoy! :3 (There will be updates of Course!)
