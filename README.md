# Fizzy Sea

A 3D adventure game about a pirate fox skeletons on fire with a water gun!

### Quick Start
* **Download**: Get the game build from the [Stardance Project Page](https://stardance.hackclub.com/projects/41053) or [Repository Releases](https://github.com/Nik0la278/Fizzy_Sea/releases/tag/1.1).
* **Launch**: Extract the archive, open the game folder, and run the `.exe` file (if it fails to launch, try running as administrator).

### Features
* Seamlessly switch between first-person and third-person camera views.
* Movement mechanics featuring sprinting and jumping.

### Controls
* **WASD**: Movement
* **Space**: Jump
* **L Shift**: Sprint
* **C**: Switch camera perspective
